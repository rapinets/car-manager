#Ітерація 002 - Фільтри і пагінація

## Мета ітерації.

Дати змогу взвужувати список автомобілів фільтрами і гортати його сторінками, не ламаючи відображення в ітерації 001.

##Що вже є
Робочий список автомобілів (ітерація 001): завантаження через GET /cars/,
відображення карток автомобілів.

## Що додаємо

- Головна(index.html) показувати останні додані
- Панель фільтрів над списком на сторінці Каталог(catalog.html): select "Марка і модель" (усі значення car_make_model +
  "Усі"), select "Паливо" (усі значення fuel_type + "Усі"), select "Рік випуску" (усі значення year + "Усі"), кнопка "Застосувати".
- Застосовані фільтри передаються як query-параметри в GET /cars/
  (car_make_model, fuel_typ, year).
- Пагінація знизу: кнопки "Назад" / "Далі", що змінюють offset
  (limit фіксований = 10) і перезавантажують список із тими самими
  фільтрами.

## Явно поза межами цієї ітерації

- Форми створення/редагування - НЕ додавати.
- Видалення - НЕ додавати.
- Окремий banner для помилок API - НЕ потрібен.

## Критерії приймання

- [ ] Зміна будь-якого фільтра і натискання "Застосувати" оновлює
      список відповідно до обраних значень.
- [ ] Кнопка "Далі" збільшує offset і довантажує наступну сторінку,
      "Назад" - зменшує (і не йде в мінус).
- [ ] Список і далі показує ті самі поля, що й в ітерації 001.
