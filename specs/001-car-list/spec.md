# Ітерація 001: Базовий список автомобілів

## Мета ітерації

Показати на сторінці список усіх автомобілів, отриманий з бекенду. Без
фільтрів, без форм, без редагування - тільки читання й відображення.

## Що вже є

Нічого. Це перша ітерація, index.html/style.css/app.js порожні або
не існують.

## Що додаємо

- Шапку сторінки з назвою "Car Catalog".
- Grid картки автомобілів: car_make_model, body, fuel_type, price, year,
  rating, is_available.
- Завантаження списку через GET /cars/ (без параметрів) одразу
  після завантаження сторінки.
- Стан завантаження (<span class="loader"></span>) зроби невелику затримку, щоб показати лоадер і стан порожнього списку
  ("Автомобілів поки немає").

## Явно поза межами цієї ітерації

- Кнопки "Додати", "Редагувати", "Видалити" - НЕ додавати.
- Фільтри і пагінація - НЕ додавати.
- Окремий banner для помилок API - НЕ потрібен (досить
  console.error за наявності мережевої помилки).

## Критерії приймання

- [ ] При відкритті сторінки виконується GET /cars/ і список
      відображається.
- [ ] Кожна картка показує всі поля, перелічені в розділі
      "Що додаємо" і посилання ("Більше->") на сторінку details.html(поки що не активну).
- [ ] Порожній список бекенду показує повідомлення, а не порожню
      сторінку.
